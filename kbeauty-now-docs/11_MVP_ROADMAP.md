# MVP 개발 로드맵

## Phase 0. 프로젝트 초기화

완료 조건:

- 모노레포 생성
- Next.js, Express, 공통 패키지 구성
- Supabase 프로젝트 연결
- Vercel 프로젝트 2개 연결
- 환경변수 구성

## Phase 1. DB 및 기본 API

작업:

- migration 작성
- places, services, attributes, sources, candidates 생성
- 공개 장소 목록 API
- 장소 상세 API
- 관리자 기본 인증

완료 조건:

- Seed 데이터 10개 조회 가능
- 필터 API 동작
- 장소 상세 응답 완성

## Phase 2. 사용자 웹

작업:

- 메인 검색 UI
- 검색 결과
- 장소 카드
- 상세 페이지
- 예약 메시지 생성기
- 변경 제보

완료 조건:

- 모바일에서 검색부터 예약 링크까지 동작
- 공개 장소만 노출
- 상태 문구가 정확히 구분됨

## Phase 3. 관리자

작업:

- 후보 목록
- 후보 상세·승인
- 장소 CRUD
- 속성·출처 편집
- 오래된 데이터 목록
- 제보 처리

완료 조건:

- candidate 승인 시 공개 테이블 반영
- 트랜잭션 실패 시 부분 저장 없음

## Phase 4. 로컬 크롤러

작업:

- CSV 입력
- Playwright 수집
- 텍스트 추출
- AI 구조화 인터페이스
- JSON 검증
- candidate 업로드

완료 조건:

- 10개 장소를 연속 처리
- 메모리 누수 없이 종료
- 중복 업로드 방지

## Phase 5. 콘텐츠·SEO

작업:

- 목록 페이지 12개
- 가이드 15개
- metadata
- sitemap
- 구조화 데이터
- 내부 링크

완료 조건:

- 모든 공개 페이지에서 title, description, canonical 확인
- 필터 조합은 noindex

## Phase 6. 초기 데이터 구축

작업:

- 후보 150곳 수집
- 100곳 공개
- 30곳 직접 확인
- 지역·업종 분포 조정

권장 분배:

| 지역 | 수량 |
|---|---:|
| 홍대 | 30 |
| 명동 | 25 |
| 강남 | 30 |
| 성수 | 15 |

| 업종 | 수량 |
|---|---:|
| 헤어 | 35 |
| 네일 | 25 |
| 헤드스파 | 20 |
| 퍼스널컬러 | 20 |

## Phase 7. 출시

체크:

- 영문 문장 검수
- 모바일 확인
- 개인정보 처리방침
- 이용약관
- 데이터 출처 표기
- Search Console
- Analytics
- 오류 모니터링

## 우선순위

```text
P0: 검색·상세·검증 데이터·관리자 승인
P1: 가이드·SEO 목록·예약 메시지
P2: 지도·즐겨찾기·업체용 페이지
P3: 회원가입·예약 제휴·다국어
```
