# 기능 완료 기준

## 1. 검색

- 지역·업종 필터가 URL에 반영됨
- 새로고침 후 동일 결과 유지
- 공개 상태 장소만 노출
- 조건 필터가 DB 속성과 정확히 연결
- 결과 0건 화면 제공

## 2. 장소 카드

- 업체명·지역·업종 표시
- 가격 또는 `Price not confirmed` 표시
- 검증 상태를 텍스트로 표시
- 마지막 확인 날짜 표시
- 잘못된 실시간 문구 없음

## 3. 장소 상세

- 서비스·가격·소요 시간 표시
- 영어·전화번호·결제·워크인 정보 표시
- 각 속성에 출처와 확인 날짜 표시
- 공식 예약 링크 제공
- 변경 제보 가능

## 4. 예약 메시지

- 서비스, 날짜, 시간, 인원 입력 가능
- 영어 메시지 생성
- 한국어 메시지 생성
- 복사 버튼 동작
- 빈 필드 예외 처리

## 5. 관리자 후보 승인

- 원본·추출·편집 데이터를 함께 표시
- 승인 시 transaction 처리
- 중간 실패 시 공개 데이터가 일부만 저장되지 않음
- 승인 후 후보 상태 변경
- 반려 사유 저장

## 6. 보안

- 관리자 API 인증 없음 시 401
- Service Role 키가 클라이언트 번들에 없음
- 입력 Zod 검증
- 임의 URL 접근 크롤러에서 사설 IP 차단
- HTML 콘텐츠 출력 시 XSS 방지

## 7. SEO

- 장소·목록·가이드에 metadata 존재
- canonical 존재
- sitemap에 공개 페이지만 포함
- 검색 조합은 noindex
- 구조화 데이터 오류 없음

## 8. 성능

- 초기 검색 결과 모바일에서 사용 가능
- 지도는 지연 로딩
- 이미지 최적화
- API 페이지네이션
- N+1 쿼리 없음

## 9. 크롤러

- 10개 URL 연속 처리 가능
- 실패 URL이 전체 실행을 중단하지 않음
- Context와 Browser 종료 보장
- 중복 candidate 방지
- 결과 JSON Schema 검증
