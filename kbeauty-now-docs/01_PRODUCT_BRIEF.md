# 제품 기획서

## 1. 문제 정의

한국을 방문한 외국인은 K-뷰티 서비스를 이용하려 할 때 다음 문제를 겪습니다.

- 한국 전화번호가 없어 예약할 수 없음
- 네이버·카카오 계정이 없어 예약 경로를 찾기 어려움
- 영어 상담 가능 여부가 불명확함
- 해외 발급 카드 결제 가능 여부가 불명확함
- 워크인 또는 당일 예약 가능 여부를 알기 어려움
- 가격과 소요 시간이 명확하지 않음
- 일반 지도 서비스의 리뷰만으로 실제 이용 가능성을 판단하기 어려움

## 2. 핵심 고객

### 1차 고객

- 서울을 여행 중인 영어 사용자
- 체류 기간 3~7일의 단기 여행객
- 한국 전화번호가 없는 사용자
- 헤어·네일·헤드스파·퍼스널컬러에 관심이 있는 사용자
- 오늘 또는 내일 이용 가능한 장소를 찾는 사용자

### 핵심 사용 상황

```text
“오늘 홍대에서 영어로 상담 가능한 헤드스파를 받고 싶다.”
“한국 전화번호 없이 예약 가능한 명동 네일숍을 찾고 싶다.”
“해외 카드로 결제할 수 있는 강남 퍼스널컬러 업체가 필요하다.”
```

## 3. 가치 제안

### 사용자 가치

- 장소를 찾는 시간을 줄임
- 예약 실패 가능성을 줄임
- 이용 전 필요한 조건을 한 화면에서 확인
- 업체에 보낼 영어·한국어 예약 메시지를 자동 생성

### 업체 가치

- 외국인 고객 유입
- 영어 페이지가 없어도 외국인에게 노출
- 전화번호·결제·언어 지원 여부를 쉽게 알림
- 향후 유료 상단 노출 및 예약 문의 연결 가능

## 4. MVP 기능

### 사용자 기능

- 지역·업종·조건별 장소 검색
- 장소 목록 및 상세 페이지
- 영어 응대·한국 전화번호 필요 여부 등 속성 표시
- 가격 범위와 소요 시간 표시
- 공식 예약 경로 연결
- 예약 문의 메시지 자동 생성
- 변경 정보 제보
- 이용 방법 가이드

### 관리자 기능

- 장소 CRUD
- 크롤링 후보 검수
- 속성별 출처·근거 관리
- 공개·비공개 전환
- 오래된 데이터 확인
- 사용자 제보 검수

## 5. MVP에서 제외할 기능

- 자체 예약 및 결제
- 실시간 빈자리 연동
- 피부과·성형외과
- 회원가입·소셜 기능
- 사용자 별점·장문 리뷰
- 다국어 동시 운영
- 전국 지역 확장
- 자동 크롤링 서버

## 6. 성공 지표

### 제품 지표

- 검색 결과 → 장소 상세 클릭률
- 장소 상세 → 예약 링크 클릭률
- 예약 메시지 복사율
- 조건 필터 사용률
- 변경 제보 수

### 콘텐츠 지표

- Search Console 노출 키워드 수
- 조건형 롱테일 키워드 상위 노출 수
- 가이드 → 장소 목록 이동률
- 국가별 유입과 이탈률

## 7. 초기 목표

- 공개 장소 100곳
- 직접 확인 장소 30곳 이상
- 검증 속성 500건 이상
- 목록 페이지 12개
- 가이드 15개
- 최소 4개 지역·4개 업종 제공
