# SEO 및 콘텐츠 계획

## 1. 목표

대형 여행 사이트와 큰 키워드에서 정면 경쟁하지 않습니다.

공략 대상:

```text
지역 + 업종 + 외국인 조건 + 행동
```

예시:

```text
walk in hair salon Hongdae
head spa in Seoul without Korean phone number
English speaking nail salon Myeongdong
personal color analysis Seoul foreign card
```

## 5. 내부 링크

```text
가이드
→ 조건형 목록
→ 장소 상세
→ 예약 경로
```

장소 상세에서는:

- 같은 지역 관련 장소
- 같은 업종 관련 장소
- 관련 가이드

## 6. 기술 SEO

- SSR 또는 ISR
- sitemap 분리
- canonical
- 구조화 데이터
- robots.txt
- 관리자·검색 조합 noindex
- 이미지 alt
- 404·폐업 장소 처리

## 7. 구조화 데이터

가능한 범위에서:

- LocalBusiness
- BeautySalon
- BreadcrumbList
- Article
- FAQPage는 실제 FAQ가 있을 때만 사용

## 8. 다국어 확장

영어 검증 후:

```text
/en
/ja
/zh-tw
```

언어별 별도 URL과 hreflang 사용.
단순 번역보다 언어별 키워드를 별도로 조사합니다.
