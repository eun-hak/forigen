# 관리자 기능 명세

## 1. 목표

관리자 페이지의 목적은 데이터를 많이 입력하는 것이 아니라, **크롤링 결과를 빠르고 정확하게 검수하는 것**입니다.

## 2. 대시보드

표시 항목:

- 공개 장소 수
- 검수 대기 후보 수
- 30일 이상 지난 속성 수
- 미처리 변경 제보 수
- 지역·업종별 장소 수
- 직접 확인 장소 수

## 3. 후보 검수 화면

3단 구조 권장:

```text
왼쪽: 원본 및 스크린샷
가운데: AI 추출 결과
오른쪽: 공개 데이터 편집 폼
```

버튼:

- 승인
- 수정 후 승인
- 재조사 필요
- 반려
- 중복 장소와 병합

## 4. 장소 관리

목록 필터:

- 상태
- 지역
- 업종
- 검증 수준
- 마지막 확인 날짜
- 정보 완성도

편집 항목:

- 기본 정보
- 서비스·가격
- 예약 채널
- 속성
- 출처
- 확인 날짜
- 공개 상태

## 5. 오래된 데이터 화면

```text
가격 30일 경과
예약 링크 오류
영어 지원 90일 경과
사용자 변경 제보 있음
```

각 항목에서:

- 재조사 목록 내보내기
- 확인 날짜 갱신
- 속성 만료 처리

## 6. 변경 제보

제보 상태:

```text
pending / reviewing / resolved / rejected
```

처리 기능:

- 장소 데이터 수정
- 출처 추가
- 제보자 이메일에 답변 여부 기록
- 허위·중복 신고 처리

## 7. 권한

MVP:

- admin 1개 역할

향후:

- editor
- verifier
- business_owner

## 8. 감사 로그

필수 기록:

- 누가
- 언제
- 어떤 필드를
- 기존 값에서
- 어떤 값으로 변경했는지
