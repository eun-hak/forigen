# K-Beauty Now 현재 운영 현황

> 기준일: 2026-08-13 (Asia/Seoul)

## 1. 요약

K-Beauty Now는 Next.js 사용자·관리자 웹, Supabase PostgreSQL/Auth, 로컬 Node.js 수집기로 구성된다. 공공데이터·Kakao·Naver·공식 웹사이트를 교차 확인하고, 자동 수집 결과는 관리자 승인 전에 공개하지 않는다.

## 2. 현재 DB 상태

- 승인된 크롤링 후보: 300개
- 검수 대기 후보: 0개
- 공개 장소: 266개
- 신규 비공개 초안: 34개
- 공식 SNS 계정: 5개
- 확인된 예약·문의 채널: 7개
- 확인된 영업시간: 1개
- 공개 가능한 구조화 메뉴: 0개

신규 34개 장소는 `draft`로 유지하며 추가 확인 전에는 사용자에게 노출하지 않는다.

## 3. 구현된 사용자 기능

- 영어·한국어 홈, 검색, 장소 상세
- 지역·업종·영어 응대·당일 문의·해외 카드·한국 전화번호 조건 필터
- Kakao 기반 목록·상세 지도
- 검증 상태, 근거, 확인일 표시
- 가격·소요 시간·예약 경로 표시
- 검색 결과 카드 전체 클릭으로 장소 상세 이동
- 검색 카드 대표 이미지와 이미지 출처 성격 표시
- 영어·한국어 예약 메시지 생성
- 변경 정보 제보
- sitemap, robots, canonical, LocalBusiness JSON-LD

## 4. 수집·보강 시스템

- LOCALDATA 미용업 데이터 import
- Kakao Local API를 이용한 전화·주소·좌표·장소 URL 보강
- Naver Local Search를 이용한 공식 웹사이트 후보 탐색
- 공식 웹사이트에서 SNS·예약 채널·영업시간·메뉴 후보 추출
- 이름·주소 기반 중복 제거와 매칭 점수
- 출처 URL, 근거 문장, 확인일, 신뢰도 저장
- 승인된 후보의 보강 정보 재동기화 명령

Instagram은 공식 웹사이트에서 직접 연결된 프로필 URL만 저장한다. 게시물·사진·설명은 복제하지 않는다.

### 수동 조사 데이터 반영

- 우선 조사 대상 200곳의 네이버·카카오 장소 정보를 수동 재확인
- 네이버 장소 매칭 179곳과 주소 검증 결과를 Supabase에 반영
- 공개 가격표가 확인된 장소의 가격 범위와 일부 소요 시간을 `place_services`에 반영
- 장소 ID, 출처 URL, 확인일, 주소 일치 여부를 `sources`와 `place_attributes`에 보존
- 재실행 가능한 import 스크립트를 `crawler/scripts`에 분리

### 대표 이미지 보강

우선 대상 200곳 모두 실제 출처가 확인되는 대표 이미지가 연결되어 있다. 생성 이미지와 반복 서비스 이미지는 사용하지 않는다.

- 공식 채널 이미지: 13곳
- 네이버 플레이스 매장 사진: 20곳
- 카카오맵 업주 등록 매장 사진: 33곳
- 카카오맵 방문·연관 사진: 86곳
- 카카오맵 외관 로드뷰: 48곳
- 합계: 200곳, 누락 0곳

이미지는 공식 이미지 → 업주 등록 매장 사진 → 방문 사진 → 외관 로드뷰 순으로 우선한다. UI에서는 `공식 이미지`, `매장 사진`, `방문 사진`, `외관 로드뷰` 배지를 구분해 표시하며, 각 속성에 원본 이미지 URL과 출처 장소 페이지를 함께 저장한다.

## 7. 안전·운영 정책

- 자동 추출 정보는 즉시 공개하지 않음
- 신규 승인 장소는 `draft`로 생성
- 사설 IP·localhost·자격 증명 URL·과도한 redirect 차단
- robots.txt 준수, 5 MB 페이지 제한, 요청 timeout 적용
- 실패 URL이 전체 수집을 중단하지 않음
- 기존 승인 후보를 재업로드할 때 `pending`으로 되돌리지 않음
- 공개 제보에 honeypot, 제출 시간, URL protocol 검증 적용
- Supabase secret을 사용하는 모듈은 `server-only`로 제한
